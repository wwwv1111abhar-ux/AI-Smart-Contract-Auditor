# 🛡️ AI Smart Contract Auditor

An AI-powered smart contract security auditor built for the ETHGlobal Hackathon 2026.

## Features
- Detects Reentrancy and other vulnerabilities.
- Built with Python, Streamlit, and Groq API.

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Add your `GROQ_API_KEY` to a `.env` file.
3. Run the app: `streamlit run app.py`
